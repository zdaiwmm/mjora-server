# PC Web 重连同步验证（2026-11-14）

基线为 Immich v3.4.1。用户报告的两个问题均发生在 PC Web：服务端删除后仍有失效缩略图；照片页打开资源、点击左上角返回后，其他资源无法点击。

## 已确认并修正的同步缺口

原时间线只接收当前连接上的删除事件，重新连接后不会核对离线期间的变化。只比较月份数量也无法识别“删除一张，同时新增一张”。

现在由 socket 连接管理统一区分首次连接和重连。重连时重新获取月份列表，刷新可见及邻近月份的成员；其他月份在滚入时再加载。保留已有月份对象及加载内容，刷新失败时继续显示此前内容，后续重连或滚动可再次尝试。

旧请求不得覆盖更新后的页面、删除或上传：月份列表和内容请求均有代次检查；较新的实时删除与更新优先于较旧响应。相册选择状态按月份替换成员，离屏月份的数量可响应更新。若导航正在等待旧月份请求，会继续等待最新成员加载后再定位。

这些改动只读取服务器照片列表，不删除本地文件、不重新上传已删除照片，也不改动 API 或数据库代码。此缺口与报告症状一致，但尚未在用户的卡住会话中取得直接证据，不能据此认定所有失效缩略图均由此造成。
